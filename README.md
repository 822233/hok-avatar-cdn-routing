# 王者荣耀国际服头像加载异常：通过 `cdn.wetest.net` 单域名分流恢复

## 问题背景

在 iPhone 上运行《王者荣耀国际服》（Honor of Kings）时，遇到玩家头像无法加载的问题：

- 游戏可以正常登录。
- 游戏场景及其他资源基本正常。
- 玩家头像不显示。
- 使用浙江服务器作为全局出口时，头像恢复正常。
- 浙江服务器仍然使用 AdGuard Home（AG）提供 DNS 服务。

本记录整理实际排查过程和目前已经验证有效的处理方法，供遇到类似问题的玩家参考。

## 网络环境

- 客户端：iPhone
- 路由器：ImmortalWrt
- DNS 环境：路由器上的 dnsmasq / SmartDNS，并使用 AdGuard Home 作为相关 DNS 上游
- 对比出口：福建本地默认出口、浙江服务器出口

不同用户的 DNS、代理和策略路由架构可能不同，结果不一定完全相同。

## 排查过程

### 1. 对比不同出口

| 网络出口 | 玩家头像 |
| --- | --- |
| 福建本地默认出口 | 不显示 |
| 全部游戏流量经浙江服务器出口 | 正常显示 |

这说明两条出口路径之间存在影响头像加载的差异，但单凭这一现象还不能判断是运营商屏蔽、CDN 调度、路由质量还是连接协议问题。

### 2. 检查 AdGuard Home

检查浙江服务器上的 AdGuard Home 日志后，确认浙江出口测试期间仍然使用 AG。

因此，单纯由 AG 过滤规则导致头像无法加载的可能性降低，但不能完全排除两种出口下 DNS 查询路径、缓存或解析结果不同所造成的影响。

### 3. DNS 抓包发现候选域名

在 ImmortalWrt 上对 DNS 流量进行抓包，记录到域名：

`cdn.wetest.net`

当时观察到的 CNAME 解析链为：

```text
cdn.wetest.net
  └── cdn.wetest.net.tegsea.tc.qq.com
      └── cdn.wetest.lmtlego.sched.apdcdn.com
```

当时记录到的 IPv4 地址包括：

```text
43.152.14.149
43.175.44.41
43.152.14.206
```

说明：以上 CNAME 和 IP 是当时抓包观察到的结果。CDN 解析可能随时间、地区和 DNS 上游变化，不应将这些 IP 视为固定地址。

## 已验证有效的解决方法

在 ImmortalWrt 的策略路由 / 分流规则中，添加域名：

```text
cdn.wetest.net
```

将该域名的流量指定为通过浙江服务器出口。

应用规则后重新进入王者荣耀国际服，玩家头像恢复正常显示。

**实测结果：只对 `cdn.wetest.net` 做浙江出口分流，即可在本测试环境中恢复头像；不需要将整个游戏的全部流量都经浙江服务器转发。**

建议优先使用域名分流，而不是将抓包时得到的 CDN IP 写死，因为 CDN IP 可能变化。

## 当前结论与尚未确认的事项

### 已经验证

- 福建默认出口下，玩家头像无法正常显示。
- 全部游戏流量走浙江出口时，玩家头像正常。
- 仅将 `cdn.wetest.net` 分流至浙江出口后，玩家头像也恢复正常。
- 浙江出口测试期间仍然使用 AdGuard Home。

### 尚未确认

- `cdn.wetest.net` 是否就是专用的玩家头像 CDN，还是头像加载链路中的某个依赖域名。
- 问题是否由福建运营商主动屏蔽造成。
- 是否由 CDN 节点调度、出口路由、IPv4 / IPv6 或 TCP / TLS / QUIC 连接差异造成。
- 其他地区、运营商和网络环境是否会出现相同问题。

因此，本文将 `cdn.wetest.net` 定义为**已实测有效的分流域名**，不将其断言为唯一或专用头像 CDN，也不把问题直接归因于福建运营商屏蔽。

## 欢迎补充测试

如果你也遇到王者国际服头像不显示，欢迎反馈：

1. 所在地区及网络运营商。
2. 使用的路由器系统（OpenWrt、ImmortalWrt 等）。
3. 将 `cdn.wetest.net` 分流到其他出口后，头像是否恢复。
4. 不同出口下该域名的 DNS 解析结果是否不同。

如果有更多用户验证成功，可以进一步确认适用范围和问题原因。
