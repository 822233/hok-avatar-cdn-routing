# 王者荣耀国际服头像加载异常：抓包定位真实头像域名

## 问题背景

在 iPhone 上运行《王者荣耀国际服》（Honor of Kings）时，遇到玩家头像无法加载的问题：

- 游戏可以正常登录。
- 游戏场景及其他资源基本正常。
- 玩家头像不显示。
- 使用浙江服务器作为全局出口时，头像恢复正常。
- 浙江服务器测试期间仍然使用 AdGuard Home（AG）。

后续通过抓包进一步定位，确认真正的头像资源域名为：

`static.hok5v5.com`

本文保留此前的排查过程，并更正早期对 `cdn.wetest.net` 的错误归因。

## 网络环境

- 客户端：iPhone
- 路由器：ImmortalWrt
- DNS 环境：路由器上的 dnsmasq / SmartDNS，并使用 AdGuard Home 作为相关 DNS 上游
- 对比出口：福建本地默认出口、浙江服务器出口

不同用户的 DNS、代理和策略路由架构可能不同，结果不一定完全相同。

## 排查过程

### 1. 对比不同出口

| 网络出口 | 玩家头像 |
| --- | --- |
| 福建本地默认出口 | 不显示 |
| 全部游戏流量经浙江服务器出口 | 正常显示 |

这说明两条出口路径之间存在影响头像加载的差异，但单凭这一现象还不能判断是运营商屏蔽、CDN 调度、路由质量还是连接协议问题。

### 2. 检查 AdGuard Home

检查浙江服务器上的 AdGuard Home 日志后，确认浙江出口测试期间仍然使用 AG。

因此，单纯由 AG 过滤规则导致头像无法加载的可能性降低，但不能完全排除两种出口下 DNS 查询路径、缓存或解析结果不同所造成的影响。

### 3. 更正头像域名：抓包确认 `static.hok5v5.com`

早期排查曾将 `cdn.wetest.net` 作为候选域名，并测试过将它分流到浙江出口。但这并不能证明它就是头像资源域名。

经过后续抓包定位，确认真正的头像资源域名是：

```text
static.hok5v5.com
```

**请以 `static.hok5v5.com` 作为头像资源域名进行分流，不要再把 `cdn.wetest.net` 当作已确认的头像域名。**

### 4. 关于此前的 `cdn.wetest.net` 测试

此前曾观察到 `cdn.wetest.net` 的 CNAME 解析链：

```text
cdn.wetest.net
  └── cdn.wetest.net.tegsea.tc.qq.com
      └── cdn.wetest.lmtlego.sched.apdcdn.com
```

当时记录到的 IPv4 地址包括：

```text
43.152.14.149
43.175.44.41
43.152.14.206
```

当时将该域名分流到浙江出口后，头像曾恢复显示。但后续抓包已经定位到真正的头像域名为 `static.hok5v5.com`，因此此前的现象不能作为 `cdn.wetest.net` 是头像域名的证据。它是否在其他资源或网络链路中发挥作用，尚未确认。

以上 CNAME 和 IP 仅为此前抓包时的历史记录，CDN 解析可能随时间、地区和 DNS 上游变化，不应将这些 IP 视为固定地址。

## 分流建议

在 ImmortalWrt / OpenWrt 的策略路由或代理分流规则中添加：

```text
static.hok5v5.com
```

将该域名的流量指定为通过能够正常加载头像的出口（本次测试中为浙江服务器）。

建议使用域名规则，不要将某次解析得到的 IP 写死，因为 CDN 地址可能变化。

**说明：** 已通过抓包确认该域名是头像资源域名。不同网络环境下是否必须分流、应选择哪个出口，仍需以实际测试为准。

## 当前结论

### 已确认

- 福建默认出口下，玩家头像无法正常显示。
- 全部游戏流量走浙江出口时，玩家头像正常。
- 浙江出口测试期间仍然使用 AdGuard Home。
- 后续抓包确认头像资源域名为 `static.hok5v5.com`。

### 尚未确认

- 问题是否由福建运营商主动屏蔽造成。
- 是否由 CDN 节点调度、出口路由、IPv4 / IPv6 或 TCP / TLS / QUIC 连接差异造成。
- 其他地区、运营商和网络环境是否会出现相同问题。
- `cdn.wetest.net` 是否参与其他游戏资源链路。

因此，本文不将问题直接归因于运营商屏蔽，也不再将 `cdn.wetest.net` 标注为头像域名。

## 欢迎补充测试

如果你也遇到王者国际服头像不显示，欢迎反馈：

如果有更多用户验证成功，可以进一步确认适用范围和问题原因。
